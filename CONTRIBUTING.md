# Contributing

IW4Iris is a finished tool to **use**, maintained by its author. It is not
an open community project.

* **Using it:** download the latest release from the
  [Releases page](https://github.com/efrot/iw4iris/releases/latest) and
  start `IW4Iris Launcher.exe`. New versions install themselves.
* **Bugs and problems:** open an
  [issue](https://github.com/efrot/iw4iris/issues) with what you did, what
  happened, and your log (in the editor: Help → Diagnostics → *Save a
  support bundle*; it contains no personal data). Issues are read, but there
  is no promise of an answer.
* **Code contributions:** pull requests are not accepted and are closed
  without review. Please do not send patches.

The licence (GPL-3.0, see LICENSE, as required by the IW4x client it is
built on) allows you to change your own copy. Such copies are not official
IW4Iris builds and do not receive IW4Iris' automatic updates.
